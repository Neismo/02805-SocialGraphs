Project Introduction & Evolution

Welcome to our course project hub for 02805 Social Data Analysis and Visualization at the Technical University of Denmark (DTU).

This web application serves as our evolving computational notebook and interactive visualization hub. Over the course of the semester, we investigate the mathematical properties of complex real-world networks, uncover community factions, perform natural language processing on graph-associated texts, and build accessible, responsive visual analytics interfaces.

As we progress through each weekly assignment and expand our analytical models, new modules and interactive investigations will be integrated directly into this portal.

🕸️

Network Topologies

Constructing directed and undirected graph structures in Python with NetworkX, analyzing in/out degree distributions, connectivity, and PageRank centralities.

🔬

Community Detection

Partitioning networks using modularity optimization (Louvain algorithm) to reveal organic clusters, thematic factions, and densely interconnected groups.

📊

Interactive Visualizations

Rendering browser-native D3.js force simulations with dynamic node inspection, auto-complete search, neighbor traversal, and custom filters.

Marvel Superhero Network

Marvel Comics Superhero Social Graph

A directed network of 303 Marvel superheroes extracted from Wikipedia category pages, linked by 1,784 directed hyperlinks. Features a full Python data pipeline, interactive D3.js force simulation, community clustering, character inspector with neighborhood traversal, and in-depth PageRank ranking.

1,784 Direct Hyperlinks (Edges)
